# Frontend guidance

For frontend presentation changes, read `.agents/skills/design-taste-frontend/SKILL.md` (Leonxlnx/taste-skill). Installed with the Skills CLI for Codex.

Use the preserve redesign mode. Keep Recall's cream paper, forest green, editorial serif headings, short Indonesian copy, and real interactive flashcard preview. Starting dials: design variance 5, motion intensity 4, visual density 3.

The existing print-inspired light theme is intentional. Preserve routes, navigation labels, authentication, source inputs, and study behavior. Keep question-answer-question flipping, keyboard controls, visible current-page navigation, and reduced-motion support.

Apply landing-page advice to the landing page; do not replace functional forms or study controls with marketing layouts. Prefer native CSS for existing animation. Self-host added fonts. Run `npm run build` and verify the affected interactions before deployment.

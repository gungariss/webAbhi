# webAbhi

Proyek Next.js dengan App Router dan React.

## Menjalankan secara lokal

```bash
npm ci
npm run dev
```

Buka http://localhost:3000. Ubah `app/page.js` untuk mengedit halaman utama.

## Build produksi

```bash
npm run build
npm start
```

## Vercel

Import repository `gungariss/webAbhi`, pilih framework Next.js, dan gunakan direktori root repository. Build command: `npm run build`. Branch produksi: `main`.
